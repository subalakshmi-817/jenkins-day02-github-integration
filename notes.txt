==============================
JENKINS DAY 02 - GITHUB INTEGRATION
==============================

What is Git?
-------------
Git is a Version Control System (VCS).
It tracks changes in source code and allows multiple developers to work together.

What is GitHub?
----------------
GitHub is a cloud platform used to store Git repositories.

What is SCM?
-------------
SCM stands for Source Code Management.
It helps manage and track source code versions.

Why integrate Jenkins with GitHub?
-----------------------------------
• Automatically download source code
• Build the latest project
• Run tests
• Enable Continuous Integration

Steps Performed
----------------
1. Created a GitHub repository.
2. Added project files.
3. Created a Jenkins Freestyle Project.
4. Selected Git under Source Code Management.
5. Entered the GitHub Repository URL.
6. Added a Windows Batch Build Step.
7. Executed Build Now.
8. Verified the Console Output.

Build Commands
----------------
dir

echo Jenkins Successfully Downloaded Files

echo Build Successful

Key Terms
-----------
